# tooni

An intuitive, ad-free animator that runs in your browser.

Create hand-drawn, frame-by-frame animations on desktop or mobile.

## Features

- Smooth drawing with adjustable brush and eraser sizes
- Fill tool
- Freeform selections: move, resize, rotate, flip, copy, paste, and delete
- Multiple layers with visibility, opacity, and reordering
- Create, duplicate, delete, and reorder frames
- Onion skin to guide your next frame
- Adjustable playback speed
- Fullscreen drawing mode
- Named projects with automatic local saving
- MP4 video export on supported browsers

## Start animating

Open the website in a modern browser. No account or installation is required.

## Project storage

Projects are saved locally in your browser on your device.

They do not sync between devices or browsers. Clearing the website’s
browser data can permanently remove saved projects.

Exporting an MP4 saves a video, not an editable project backup.

## Hosting

tooni is a static website built with HTML, CSS, and JavaScript,
hosted on GitHub Pages.
